# Personal Portfolio – Assignment 1
## Project Description
This project is a responsive personal portfolio website created for Assignment 1 – Foundation & AI Integration.
The website includes an About Me section, two projects, a Skills section, and a Contact form. It was built using HTML, CSS, and JavaScript.
## Main Features
- Responsive design for desktop, tablet, and mobile
- About Me, Projects, Skills, and Contact sections
- Dark/light theme toggle
- Greeting based on the time of day
- Contact form interaction
- Smooth scrolling
## Setup Instructions
No installation is required.
1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
You can also open the project using the Live Server extension in VS Code.
