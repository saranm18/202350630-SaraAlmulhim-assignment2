# Personal Portfolio – Assignment 2
## Project Description
This project is an updated version of my personal portfolio website from Assignment 1.
For Assignment 2, I added more JavaScript interaction, data handling, form validation, and CSS transitions. The website is built using HTML, CSS, and JavaScript.

## Main Features
- Responsive design for desktop, tablet, and mobile
- About Me, Projects, Skills, and Contact sections
- Project filtering by category
- Dark/light theme toggle
- Theme preference saved using localStorage
- Greeting based on the time of day
- Contact form validation and user feedback
- Hover effects and CSS transitions
- Smooth scrolling

## Setup Instructions
No installation is required.
1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
You can also run the project using a local server such as Live Server in VS Code or Python HTTP Server.
