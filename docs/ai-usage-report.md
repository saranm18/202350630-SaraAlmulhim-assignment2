# AI Usage Report

## 1. Tools Used & Use Cases
I used ChatGPT as the main AI-assisted tool for this assignment.
I used it for:

- Breaking the assignment requirements into clear steps.
- Suggesting a simple structure for the portfolio website.
- Providing starter examples for HTML, CSS, and JavaScript.
- Reviewing my code and checking the assignment requirements.
- Helping with responsive design using CSS Grid, Flexbox, and media queries.
- Helping with JavaScript features such as the greeting, theme toggle, and contact form.
- Helping organize the README and technical documentation.
I reviewed the suggestions before using them and made changes to the content, comments, and documentation.

## 2. Benefits & Challenges
### Benefits
Using AI helped me understand the assignment requirements and organize the project faster.
It was also useful for explaining code that I did not fully understand and for showing me how CSS Grid, Flexbox, and media queries can be used for responsive design.

### Challenges and Limitations
Some AI suggestions were more detailed than I needed for this assignment, so I had to review and simplify some parts.
I also learned that AI suggestions still need to be checked because they may not always match the exact assignment requirements.

## 3. Learning Outcomes
While using AI, I learned more about:

- Organizing HTML, CSS, and JavaScript into separate files.
- Using semantic HTML elements.
- Using CSS Grid and Flexbox.
- Using media queries for responsive design.
- Using JavaScript to interact with HTML elements.
- Using `classList.toggle()` for the dark/light theme.
- Handling a form submission without a backend.
- Writing clearer project documentation.
I also learned that AI is more useful when I use it for explanations and reviewing my work instead of only replying on generated code.

## 4. Responsible Use & Modifications
I reviewed the AI-generated suggestions before using them in my project.

I changed some wording, added and changed comments, personalized the JavaScript messages, simplified the README, and checked that the code matched the assignment requirements.
I tested the website and made sure I understood the main HTML, CSS, and JavaScript features while completing the assignment.

The final project includes changes and decisions I made while reviewing and improving the AI suggestions.
