# AI Usage Report

## 1. Tools Used & Use Cases
I used ChatGPT as the main AI-assisted tool for this assignment.
I used it for:

- Breaking the Assignment 2 requirements into clear steps.
- Reviewing my Assignment 1 portfolio and planning the new features.
- Helping add project filtering using JavaScript.
- Helping save the dark/light theme preference using `localStorage`.
- Helping create contact form validation and user feedback.
- Suggesting CSS transitions and hover effects.
- Reviewing my HTML, CSS, and JavaScript code.
- Helping test and debug problems, including a browser caching issue.
- Helping update the README and technical documentation.

I reviewed the suggestions before using them and made changes to the code, comments, wording, and documentation.

## 2. Benefits & Challenges

### Benefits
Using AI helped me organize the assignment into smaller steps and understand how the new features worked.

It was useful for explaining JavaScript concepts such as filtering elements, using `localStorage`, form validation, and adding or removing CSS classes.

It also helped me debug problems and decide how to test each feature before committing my changes.

### Challenges and Limitations
Some AI suggestions were more detailed than I needed, so I simplified parts of the code and documentation.

I also learned that problems are not always caused by the code itself. For example, browser caching caused one of the JavaScript features to appear as if it was not working.

AI suggestions still needed to be reviewed and tested to make sure they matched the assignment requirements.

## 3. Learning Outcomes
While using AI, I learned more about:

- Filtering HTML elements using JavaScript and `data` attributes.
- Saving information in the browser using `localStorage`.
- Validating form inputs and displaying error messages.
- Using JavaScript to add and remove CSS classes.
- Adding CSS transitions and hover effects.
- Testing features before committing changes with Git.
- Debugging browser-related problems.
- Writing clearer project documentation.

I also learned that AI is more useful when I use it for explanations, debugging, and reviewing my work instead of only relying on generated code.

## 4. Responsible Use & Modifications
I reviewed the AI-generated suggestions before using them in my project.

I changed wording, comments, and some code so that the project stayed simple and matched my understanding. I also tested the project filtering, theme preference, form validation, responsive design, and hover effects before considering the features complete.

The final project includes changes and decisions I made while reviewing, testing, and improving the AI suggestions.
