## 2. Benefits & Challenges

### Benefits
Using AI helped me organize the assignment into smaller steps and understand how the new features worked.

It was useful for explaining JavaScript concepts such as filtering elements, using `localStorage`, form validation, and adding or removing CSS classes.

It also helped me debug problems and decide how to test each feature before committing my changes.

### Challenges and Limitations
Some AI suggestions were more detailed than I needed, so I simplified parts of the code and documentation.

I also learned that problems are not always caused by the code itself. For example, browser caching caused one of the JavaScript features to appear as if it was not working.

AI suggestions still needed to be reviewed and tested to make sure they matched the assignment requirements.
